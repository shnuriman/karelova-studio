# Karelova Studio: онлайн-версія (GitHub Pages + Supabase)

Інтерфейс лежить у `docs/`, дані живуть у вашому проєкті Supabase. Вхід один: email і пароль.

## 1. Supabase (безкоштовно)
1. Створіть проєкт на supabase.com.
2. SQL Editor → вставте вміст `supabase.sql` → Run.
3. Authentication → Users → Add user: вкажіть свій email і пароль (позначте автопідтвердження, якщо є така опція).
4. Вимкніть самореєстрацію: Authentication → налаштування Sign In / Providers → вимкніть «Allow new users to sign up». Назви пунктів у панелі можуть відрізнятись.
5. Project Settings → API: скопіюйте Project URL та публічний ключ (anon / publishable).

## 2. Налаштуйте застосунок
Відкрийте `docs/config.js` і вставте URL та ключ. Ключ `service_role` вставляти не можна.
Публічний ключ безпечний, бо доступ до даних захищений політикою RLS з `supabase.sql`.

## 3. GitHub
1. Створіть ПУБЛІЧНИЙ репозиторій і завантажте туди вміст цієї папки. Дані клієнтів у репозиторій не потрапляють.
2. Settings → Pages → Source: Deploy from a branch → Branch: main, папка `/docs`.
3. Через хвилину сайт відкриється за адресою `https://ваш-логін.github.io/назва-репозиторію/`.

## 4. На телефоні
- iPhone: відкрийте посилання в Safari → Поділитися → «На екран Додому».
- Android: Chrome → меню → «Встановити застосунок».

## Важливо
- Безкоштовний проєкт Supabase призупиняється після тижня без активності. Дані зберігаються, потрібно натиснути Restore в панелі.
- Налаштування → «Експорт копії» зберігає резервну копію у файл. Робіть її час від часу.
- Якщо відкрити застосунок на двох пристроях і змінити дані на обох, останнє збереження виявить конфлікт версій і оновить сторінку. Так одна копія не затре іншу.
- Без інтернету застосунок відкривається з локальної копії; зміни підуть на сервер, коли з’явиться зв’язок (угорі з’являється червона позначка).
- Фото зберігаються всередині даних. Багато великих фото збільшать базу. Ліміт безкоштовного плану 500 МБ.
